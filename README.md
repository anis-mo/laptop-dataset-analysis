# 💻Laptop Price & Specifications Analysis

## 📌Project Overview

This project analyzes laptop specifications and prices using Microsoft Excel.

The project focuses on cleaning the dataset, analyzing laptop characteristics using PivotTavles, and creating an interactive dashboard to identify pricing patterns and differences beteen laptop categories.

The project was completed in three main stages:

1. Data Cleaning
2. PivotTable Analysis
3. Dashboard Development

---

## Objectives

The objective of this project is to transform raw laptop specification data into a clean and structured dataset, analyze pricing patterns using PivotTables, and build an interactive dashboard that provides insights into laptop prices, companies, types, operating system , and ram.

---

## 🗒️Dataset

The dataset contains laptop specifications and prices:

- Company
- TypeName
- Inches
- ScreenResolution
- Cpu
- Ram (GB)
- Memory
- Type
- Gpu
- OpSys
- Weight (Kg)
- Price

## 🧹Data Cleaning

- Removed unnecessary columns such as "Unnamed : 0"
- Removed completely blank rows
- Checked for missing values 
- Removed duplicate records
- Kept missing values blank in numerical columns
- standardized data types
- Converted numerical columns to numeric format
- Kept categorical columns as text
- Checked the consistency of laptop specifications
- Formatted the dataset as an Excel Table

## PivotTable Analysis

PivotTables were created to analyze laptop prices and specifications.

## 🔎Analysis Questions

1. Which companies have the highest average laptop price ?
2. Which laptop types have the highest average price ?
3. Which categories offer the most laptops ?
4. How does RAM affect the average laptop price ?
5. What is the average price by operating system ?
